# 💳 Mini Bank in C

A simple terminal banking system developed in C to practice programming logic, file handling, structs, and code organization.

---

## 🚀 Features

* ✅ Account registration
* ✅ Hidden password login
* ✅ Withdraw system
* ✅ Deposit system
* ✅ Money transfer between accounts
* ✅ Transaction history
* ✅ Automatic data saving (`dados.txt`)
* ✅ Terminal interface
* ✅ Organized function-based structure

---

## 🛠️ Technologies Used

* C Language
* `stdio.h`
* `stdlib.h`
* `string.h`

---

## 📚 Concepts Practiced

This project was created to study and improve:

* Structs
* Functions
* Loops (`for`, `while`)
* Conditionals (`if`, `else`)
* File handling
* Arrays and strings
* Code organization
* Programming logic
